# Cabling Standardization Program

> A practical operating standard for making enterprise data center cabling safer, easier to trace, faster to troubleshoot, and simpler to audit.

## Business challenge

Inconsistent routing, labeling, slack management, and documentation increase troubleshooting time and create avoidable change risk. The goal was to establish repeatable physical-layer practices that improve traceability without disrupting production services.

## My role

- Audited copper and fiber paths, labels, patch-panel mappings, and rack conditions
- Organized pathways and corrected cable-routing issues during approved windows
- Applied consistent color, endpoint, and asset-labeling practices
- Tested fiber links and verified connectivity after changes
- Updated CMDB records, rack documentation, and cabling layouts

## Standardization framework

### Labeling

- Label both ends before installation or disconnection
- Use a consistent source-to-destination naming structure
- Keep identifiers readable, durable, and aligned with documentation

### Routing

- Separate data and power paths where required
- Respect bend radius and avoid connector strain
- Route through designated horizontal and vertical managers
- Maintain service loops without blocking airflow or access

### Fiber handling

- Protect and clean connectors before insertion
- Validate optic and fiber type compatibility
- Test links with approved equipment, including OTDR where appropriate

### Documentation

- Record source port, destination port, media type, path, and service association
- Update records in the same change window
- Flag undocumented or abandoned cabling for review before removal

## Quality gates

| Gate | Evidence |
|---|---|
| Identification | Matching labels at both endpoints |
| Physical quality | Correct pathway, bend radius, slack, and strain relief |
| Connectivity | Link verification or approved test result |
| Traceability | Current port map and CMDB record |
| Closeout | Before/after review and exception log |

## Operational result

- Contributed to a **30% reduction in cable-related incidents**
- Improved network-path traceability and maintenance efficiency
- Reduced avoidable rework through link testing and standardized closeout
- Made audit preparation and troubleshooting faster with current documentation

## Reusable audit checklist

- [ ] Labels match at both endpoints
- [ ] Cable type and optics are compatible
- [ ] Bend radius and connector protection meet standards
- [ ] Pathways are organized and do not obstruct airflow
- [ ] Slack is controlled and serviceable
- [ ] Link has been tested and verified
- [ ] Port map and CMDB entries are current
- [ ] Abandoned cabling is identified for approved removal
